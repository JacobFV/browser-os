# Showcase App

Component gallery and showcase application for browser-os.

## Overview

The Showcase app provides a Storybook-like gallery for browsing and testing browser-os components:
- Component examples
- Theme showcase
- Interactive demos
- API documentation

## Features

- **Component Gallery**: Browse all UI components
- **Theme Showcase**: See all themes in action
- **Interactive Demos**: Try components interactively
- **Documentation**: Component API documentation

## Usage

Launch the Showcase app to explore browser-os components. The showcase includes:

### Components

- Buttons (all variants)
- Inputs
- Dialogs
- Icons
- And more...

### Themes

- Win95 theme demo
- macOS theme demo
- Monaco theme demo
- Glass theme demo

### Examples

- Basic usage examples
- Advanced patterns
- Integration examples

## Development

```bash
# Run showcase
pnpm --filter @browser-os/showcase dev
```
