# Basic Windowing Example

Example demonstrating basic windowing functionality in browser-os.

## Overview

This example shows how to:
- Open windows
- Manage window state
- Handle window events
- Arrange windows

## Usage

```bash
# Run example
pnpm --filter @browser-os/example-basic-windowing dev
```

## Features Demonstrated

- Opening windows programmatically
- Window focus management
- Window state changes
- Window arrangement patterns

## Code Examples

See `src/App.tsx` for complete examples of:
- Creating windows
- Focusing windows
- Arranging windows
- Listening to window events
