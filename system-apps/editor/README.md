# Editor App

Code editor application for browser-os using Monaco Editor.

## Overview

The Editor app provides a full-featured code editor with:
- Monaco Editor integration
- Multi-tab support
- Syntax highlighting
- Code completion
- Optional Y-Monaco for collaboration

## Features

- **Monaco Editor**: VS Code editor engine
- **Multi-Tab**: Open multiple files
- **Syntax Highlighting**: Support for many languages
- **Code Completion**: IntelliSense
- **Collaboration**: Optional Y-Monaco integration

## Usage

Launch the Editor app to start editing files. The editor supports:
- Opening files from the file system
- Creating new files
- Saving files
- Multiple tabs
- Find and replace

## File Operations

### Open File

1. File → Open
2. Navigate to file
3. Select and open

### Save File

- **Ctrl+S**: Save current file
- **Ctrl+Shift+S**: Save as

### New File

- **Ctrl+N**: New file
