# Word Processor

Full-featured word processor application for browser-os.

## Features

- Multiple document windows (each document in its own window)
- Rich text editing (bold, italic, underline, fonts, sizes, alignment)
- File operations (save/load using system file dialogs)
- Real-time word and character count
- Menu bar and toolbar

## Keyboard Shortcuts

- **Ctrl+N**: New document
- **Ctrl+O**: Open document
- **Ctrl+S**: Save
- **Ctrl+Shift+S**: Save As
- **Ctrl+B/I/U**: Bold/Italic/Underline
- **Ctrl+Z/Y**: Undo/Redo
- **Ctrl+X/C/V**: Cut/Copy/Paste

## File Format

Documents are saved as HTML files in the virtual filesystem. Default location: `vfs://documents/`.
