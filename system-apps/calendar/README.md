# Calendar App

Calendar application for browser-os.

## Overview

The Calendar app provides calendar functionality with:
- Month and week views
- Event management
- ICS import/export
- Event reminders

## Features

- **Views**: Month, week, day views
- **Events**: Create and manage events
- **ICS Support**: Import/export ICS files
- **Reminders**: Event reminders (future)

## Usage

Launch the Calendar app to view and manage your calendar. The app supports:
- Viewing calendar in different views
- Creating events
- Editing events
- Importing ICS files

## Views

- **Month**: Full month view
- **Week**: Week view with time slots
- **Day**: Single day view

## Events

### Create Event

1. Click on date/time
2. Enter event details
3. Save

### Edit Event

1. Click on event
2. Edit details
3. Save

## ICS Import

Import calendar files:
1. File → Import
2. Select ICS file
3. Events are imported
