# Monitor App

Process monitor and system diagnostics application for browser-os.

## Overview

The Monitor app provides system monitoring and diagnostics:
- Process table
- Performance graphs
- Log viewer
- Event bus inspector

## Features

- **Process Table**: View all running processes
- **Performance**: CPU and memory graphs
- **Logs**: View system logs
- **Events**: Inspect event bus

## Usage

Launch the Monitor app to monitor system performance. The app shows:

### Process Table

- Process ID (PID)
- App ID
- State (running, suspended, etc.)
- CPU usage
- Memory usage
- Actions (kill, suspend, resume)

### Performance Graphs

- CPU usage over time
- Memory usage over time
- Network activity

### Logs

- System logs
- Error logs
- Warning logs
- Info logs

### Event Bus

- View event bus channels
- Monitor events in real-time
- Filter events

## Process Actions

- **Kill**: Terminate process
- **Suspend**: Pause process
- **Resume**: Resume suspended process
