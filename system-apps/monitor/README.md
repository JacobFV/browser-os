# Monitor App

Process monitor and system diagnostics application for browser-os.

## Features

- **Process Table**: View all running processes with PID, state, CPU, memory
- **Performance Graphs**: CPU and memory usage over time
- **Logs**: View system logs (info, warn, error)
- **Event Bus**: Inspect event bus channels and monitor events

## Process Actions

- **Kill**: Terminate process
- **Suspend**: Pause process
- **Resume**: Resume suspended process
