# Store App

App store application for browser-os.

## Overview

The Store app provides an app catalog and installation system:
- Browse available apps
- Install apps
- Update apps
- Uninstall apps

## Features

- **App Catalog**: Browse available apps
- **Installation**: Install apps from store
- **Updates**: Update installed apps
- **Management**: Uninstall apps

## Usage

Launch the Store app to browse and install apps. The store shows:
- Featured apps
- Categories
- Search
- Installed apps

## Installing Apps

1. Browse or search for app
2. Click on app
3. Click Install
4. Review permissions
5. Confirm installation

## Updating Apps

1. Go to Installed section
2. View available updates
3. Click Update
4. App updates automatically

## Uninstalling Apps

1. Go to Installed section
2. Find app
3. Click Uninstall
4. Confirm

## App Manifest

Apps are installed from manifests:
- App metadata
- Required permissions
- Entry point
- Version information
