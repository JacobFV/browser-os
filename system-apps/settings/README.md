# Settings App

System settings application for browser-os.

## Overview

The Settings app provides a control panel for configuring browser-os:
- Appearance settings
- Mount management
- Keyboard shortcuts
- Permissions management
- System information

## Features

- **Appearance**: Theme selection, accent colors
- **Mounts**: Manage filesystem mounts
- **Keyboard**: Customize keyboard shortcuts
- **Permissions**: Manage app permissions
- **About**: System information

## Usage

Launch the Settings app to configure browser-os. Settings are organized into sections:

### Appearance

- Theme selection (Win95, macOS, Monaco, Glass)
- Accent color
- Font settings

### Mounts

- View mounted filesystems
- Add new mounts
- Remove mounts

### Keyboard

- View keyboard shortcuts
- Customize shortcuts

### Permissions

- View app permissions
- Grant/revoke permissions

### About

- System version
- Build information
- License

## Settings Persistence

Settings are automatically saved to:
- User preferences: localStorage
- Workspace settings: localStorage
- System preferences: localStorage
