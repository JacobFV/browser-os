# Files App

File manager application for browser-os.

## Features

- File and folder navigation
- Mount point management
- File preview
- Copy, move, rename, delete operations
- Drag and drop support

## Keyboard Shortcuts

- **Ctrl+N**: New folder
- **Ctrl+C**: Copy
- **Ctrl+V**: Paste
- **Ctrl+X**: Cut
- **Delete**: Delete selected
- **F2**: Rename
- **F5**: Refresh
