# Notes App

Notes application for browser-os with Yjs collaboration support.

## Overview

The Notes app provides a collaborative note-taking experience with:
- Markdown support
- Yjs real-time collaboration
- Cursor presence
- Rich text editing

## Features

- **Markdown**: Markdown editing and preview
- **Collaboration**: Real-time collaboration via Yjs
- **Cursors**: See other users' cursors
- **Rich Text**: Rich text formatting

## Usage

Launch the Notes app to start taking notes. The app supports:
- Creating new notes
- Editing markdown
- Real-time collaboration
- Cursor presence

## Markdown

The app supports standard markdown:
- Headers (# ## ###)
- Bold (**text**)
- Italic (*text*)
- Lists (- item)
- Links ([text](url))
- Code blocks

## Collaboration

With Yjs integration:
- Multiple users can edit simultaneously
- See other users' cursors
- Real-time synchronization
- Conflict resolution
