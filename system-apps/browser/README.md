# Browser App

Web browser application for browser-os with iframe-based webview.

## Overview

The Browser app provides web browsing capabilities with:
- Iframe-based webview
- Tab management
- Address bar
- Sandboxed navigation

## Features

- **Web Browsing**: Navigate web pages
- **Tabs**: Multiple tabs support
- **Address Bar**: URL navigation
- **Sandboxing**: Secure iframe sandboxing

## Usage

Launch the Browser app to start browsing. The browser supports:
- Navigating to URLs
- Opening multiple tabs
- Back/forward navigation
- Bookmarking (future)

## Tabs

- **Ctrl+T**: New tab
- **Ctrl+W**: Close tab
- **Ctrl+Tab**: Switch tabs

## Security

The browser uses iframe sandboxing:
- Restricted permissions
- CSP enforcement
- Isolated from main app
